# Fibi Chuppi (Phoebe Chupi) — OpenPeon Sound Pack

CESP v1.0 sound pack featuring the viral **Phoebe Chupi** (*Fibi Chuppi*) cube noises from *Wuthering Waves*.

## Sounds Included

- sounds/phoebe-chupi.mp3 — Original Phoebe Chupi meme clip (3.77s)
- sounds/phoebe-chupi-short.mp3 — Tight opening phrase (1.54s)
- sounds/phoebe-chupi-cue.mp3 — Quick Chupi alert cue (1.20s)
- sounds/phoebechubby.mp3 — Short Phoebe Chubby variant (1.72s)
- sounds/fibi-chubi.mp3 — Extended Fibi Chubi variant (4.50s)

## Installation

`ash
peon packs install duydat255-creator/fibi-chuppi
peon packs use fibi-chuppi
`

Or install locally:

`ash
peon packs install-local ~/.peon-ping/packs/fibi-chuppi
peon packs use fibi-chuppi
peon preview
`
